Inserire in questa cartella soltanto le immagini effettivamente utilizzate dalla guida.

Formati consigliati: WebP, PNG o JPG ottimizzati per il web.
Usare nomi file descrittivi, per esempio: selezione-sezione-trasparenza.webp.
Le schermate devono provenire dall'interfaccia aggiornata, non contenere dati personali
o credenziali e restare comprensibili anche quando il colore istituzionale cambia.

Nel template PHP usare <figure>, <img> e <figcaption>, costruire l'indirizzo con
get_theme_file_uri() e inserire sempre un testo alternativo significativo.
